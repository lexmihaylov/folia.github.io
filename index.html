Your Markdown library,

Folia is a filesystem-first knowledge base for Markdown notes. It scans a configured root folder, renders a live tree, and lets you create, edit, rename, copy, and move documents directly on disk.

FEATURES

Everything you need for a serious note library

Filesystem-backed

No database. Reads and writes Markdown files directly in your configured root folder.

NAS friendly

Point your library root to any SMB-mounted path — your notes live on your NAS.

Full-text search

Search across your entire Markdown library and jump to documents in seconds.

Live editor

Write Markdown with live preview, theme toggle, and syntax highlighting.

Tree operations

Create, rename, copy, cut, move, and delete files and folders inline.

Vault encryption

Encrypted .emd notes alongside regular .md files.

Update scripts

Built-in update scripts let you pull the latest release and restart Folia safely in seconds.

Standalone deploy

Package a Next.js standalone build and run it on lightweight hosts.

USAGE

How Folia works

01

Run the installer

One command downloads the latest release, prompts for your library root, installs to /opt/folia, and registers the folia service via systemd.

02

Mount your notes storage

Mount your NAS via SMB, set libraryRoot in folia.config.json to that path, and every .md file in that tree becomes a document.

03

Open the app

Browse http://localhost:3000, create an account at /setup, and start writing. The editor supports live preview, and the tree reflects disk state in real time.

CONTRIBUTE

How to contribute

01

Start with an issue

Open a bug report or feature request before writing code. Include reproduction steps and expected behavior so the intent is clear.

02

Keep changes small

Prefer focused, atomic PRs. Follow the existing code style (TypeScript, 2-space indent). Avoid unrelated refactors in the same change.

03

Review before merging

All AI-generated and human-written code is reviewed for correctness, security, edge cases, and maintainability before it lands.
